# Test Execution Report

## Объект тестирования

REST API публичного сервиса Restful Booker.

## Область

- Authentication
- Booking CRUD
- Filtering
- Input validation
- Authorization
- HTTP status codes
- Health-check

## Покрытие

| Область | Покрытие |
|---|---|
| Авторизация | Позитивные и негативные сценарии |
| Создание бронирования | Позитивные, обязательные поля, типы данных |
| Получение | Список, ID, несуществующий ID |
| Фильтрация | Имя, фамилия, даты, комбинации |
| PUT | Успешное обновление и негативные сценарии |
| PATCH | Частичное обновление и негативные сценарии |
| DELETE | Удаление, отсутствие авторизации, повторное удаление |
| Health-check | `/ping` |
