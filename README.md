# Restful Booker — QA Test Project

> Тестирование REST API публичного сервиса бронирования **Restful Booker**.

[![API](https://img.shields.io/badge/API-REST-blue)](https://restful-booker.herokuapp.com/)
[![Tool](https://img.shields.io/badge/Postman-API%20Testing-orange)](https://www.postman.com/)
[![Documentation](https://img.shields.io/badge/Test%20Documentation-Excel-green)](#тестовая-документация)

## О проекте

Цель проекта — провести функциональное тестирование REST API сервиса бронирования, подготовить тестовую документацию, автоматизировать базовые проверки в Postman и зафиксировать выявленные дефекты.

## Что протестировано

- авторизация;
- создание бронирования;
- получение бронирования по ID;
- получение списка бронирований;
- фильтрация по `firstname`, `lastname`, `checkin`, `checkout`;
- полное обновление через `PUT`;
- частичное обновление через `PATCH`;
- удаление через `DELETE`;
- проверка авторизации при изменении данных;
- валидация входных данных;
- health-check `/ping`.

## Тестовая документация

### Тест-кейсы

В Excel-файле представлены позитивные и негативные сценарии.

Для каждого сценария указаны:

- ID;
- endpoint;
- тип теста;
- название;
- предусловия;
- шаги;
- ожидаемый результат;
- приоритет.

**[Открыть тест-кейсы](test-cases/Restful_Booker_Тест-кейсы_и_Баг-репорты.xlsx)**

### Postman

Коллекция содержит последовательный сценарий работы с API:

`Авторизация → создание бронирования → получение → фильтрация → PUT → PATCH → DELETE → проверка удаления`

Для динамических данных используются переменные:

- `token`;
- `bookingId`;
- `firstname`;
- `lastname`;
- `checkin`;
- `checkout`.

**[Открыть Postman Collection](postman/Restful_Booker_Postman_Collection.json)**

### Баг-репорты

Дефекты вынесены в отдельные Markdown-файлы.

Каждый баг содержит:

- severity;
- priority;
- endpoint;
- шаги воспроизведения;
- ожидаемый результат;
- фактический результат;
- влияние.

**[Перейти к баг-репортам](bugs/)**

## Запуск

1. Скачать `postman/Restful_Booker_Postman_Collection.json`.
2. Импортировать коллекцию в Postman.
3. Выполнить запрос авторизации.
4. Выполнить создание бронирования.
5. Запустить остальные запросы.
6. Проверить результаты автоматических тестов.
