# BUG-002 — PUT принимает пустые строки и некорректные значения вместо валидационной ошибки.

**Endpoint:** `PUT /booking/:id`  
**Severity:** `Major`  
**Priority:** `High`

## Шаги воспроизведения

1. Получить token. 2. Создать бронь. 3. PUT с firstname='', totalprice='сто рублей', отрицательным totalprice или checkout раньше checkin.

## Ожидаемый результат

400 Bad Request; некорректное значение не сохраняется.

## Фактический результат

200 OK; некорректное значение может быть сохранено.

## Влияние

Некорректные данные попадают в систему.
