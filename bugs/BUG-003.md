# BUG-003 — PATCH допускает некорректные типы и бизнес-некорректные значения.

**Endpoint:** `PATCH /booking/:id`  
**Severity:** `Major`  
**Priority:** `High`

## Шаги воспроизведения

1. Получить token. 2. Создать бронь. 3. PATCH с lastname=100, totalprice=-500 или checkout раньше checkin.

## Ожидаемый результат

400 Bad Request.

## Фактический результат

200 OK; некорректное значение сохраняется.

## Влияние

Нарушение целостности данных.
