# BUG-006 — Health-check возвращает 201 Created вместо 200 OK.

**Endpoint:** `GET /ping`  
**Severity:** `Low`  
**Priority:** `Low`

## Шаги воспроизведения

1. Выполнить GET /ping.

## Ожидаемый результат

200 OK.

## Фактический результат

201 Created.

## Влияние

Не влияет на доступность, но нарушает ожидаемую семантику health-check.
