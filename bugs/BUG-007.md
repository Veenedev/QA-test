# BUG-007 — Некорректные типы/обязательные поля могут обрабатываться недостаточно строго.

**Endpoint:** `POST /booking`  
**Severity:** `Major`  
**Priority:** `High`

## Шаги воспроизведения

1. Отправить POST с некорректным типом totalprice либо отсутствующим обязательным полем. 2. Проверить код и сохранённую запись.

## Ожидаемый результат

400 Bad Request; запись не создаётся.

## Фактический результат

В опубликованных прогонах встречаются 500 либо 200 с некорректно сохранёнными значениями.

## Влияние

Клиент получает некорректный результат вместо предсказуемой валидации.
