# BUG-008 — Дробное значение totalprice может сохраняться с потерей точности.

**Endpoint:** `POST /booking`  
**Severity:** `Medium`  
**Priority:** `Medium`

## Шаги воспроизведения

1. Создать бронь с totalprice=99.99. 2. Получить бронь по ID. 3. Сравнить значение.

## Ожидаемый результат

Сохраняется 99.99.

## Фактический результат

В опубликованном тесте выявлена потеря точности.

## Влияние

Финансовое значение искажается.
