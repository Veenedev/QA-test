# BUG-001 — Фильтр по checkin не возвращает созданную бронь с той же датой заезда.

**Endpoint:** `GET /booking?checkin=...`  
**Severity:** `Major`  
**Priority:** `High`

## Шаги воспроизведения

1. Создать бронь. 2. Сохранить bookingid и checkin. 3. Выполнить GET /booking?checkin={checkin}. 4. Проверить наличие bookingid.

## Ожидаемый результат

200 OK; созданный bookingid присутствует.

## Фактический результат

200 OK; созданный bookingid отсутствует.

## Влияние

Невозможно надёжно получить записи по дате заезда; затрагивает поиск и бизнес-сценарии.
